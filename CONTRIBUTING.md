# Contributing Guidelines

Thank you for your interest in contributing to **Awesome AI Research Tools**! Your contributions keep this list accurate, high-quality, and useful for scientists, engineers, and academics worldwide.

## Inclusion Criteria

To maintain the quality of this repository, suggested tools should satisfy the following criteria:

1. **Academic or Research Utility:** The tool must directly assist in literature discovery, paper analysis, writing/typesetting, experimentation, reproducibility, or data visualization.
2. **Active Maintenance:** The project must be currently active (e.g., maintained codebase or active web service).
3. **No Low-Quality Wrappers:** Generic thin wrappers over basic LLM APIs with no research-specific features are discouraged.
4. **Transparent Pricing / Openness:** Clearly state whether the tool is Open Source (`[OSS]`), Free, Freemium, or Paid.

## Submission Format

Please add new items to the appropriate category in alphabetical order using this format:

```markdown
- [Tool Name](https://tool-website.com/) — Concise 1-2 sentence description explaining the key capability and why researchers should care.
```

## Pull Request Checklist

Before opening a PR:

- [ ] Check if the link is valid and resolves over HTTPS.
- [ ] Ensure the tool isn't already listed in another section.
- [ ] Add the item to the correct section in alphabetical order.
- [ ] Keep the description objective, concise, and free from promotional buzzwords.
