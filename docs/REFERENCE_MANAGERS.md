# Modern Reference Managers & BibTeX Workflows

Guide to pairing reference managers with AI tools for automated BibTeX sanitization and citation mapping.

---

### 1. Zotero + Better BibTeX
- **Why it matters:** Generates stable, deterministic citation keys (e.g., `sajjadi2026awesome`) and auto-exports synchronized `.bib` files directly into Overleaf or local LaTeX directories.
- **Recommended Plugins:**
  - *Zotero Night*: Dark mode interface.
  - *Zotero DOI Manager*: Auto-fetches missing DOIs and verified publication dates.
  - *Zotero-SciHub / Unpaywall*: Automatic open-access PDF retrieval.

---

### 2. Obsidian Academic Knowledge Graphs
- Using Markdown-linked notes (`[[citekey]]`) to build interconnected literature reviews.
- Integrate with `BibTeX plugin` to link paper notes directly to PDFs.
